# Validation

Version 0.3.0 validated on 20 October 2026 using Windows, JDK 17.0.20.1, Gradle 9.3.1, AGP 9.1.1, Android SDK 36 and a Pixel_7a x86_64 Android 14/API 34 emulator. No physical device was attached. The emulator ran without host audio output.

## Executed results

- Debug APK: built, installed and launched successfully. The Windows build/install/launch helper was also exercised against the emulator.
- Unit tests: **39 passed, 0 failed**. The original 19 discovery/search/input/lyrics tests still pass. Seven metadata-policy tests cover contact/query validation, concurrency/rate/cooldown behavior, recording identity and attributed route edges. Nine ReplayGain tests cover bounded tag readers, track/album/peak policy, unity sample preservation, PCM scaling, saturation and malformed input.
- Instrumented tests: **43 passed, 0 failed**. The app UI and media browsing/queue flow still pass. New tests verify consent before network dispatch, fixed endpoints/identified requests, response identity and discarded supplementary fields, cooldown without automatic retries, stream-bound gain and empty audio-pipeline buffers. A real ExoPlayer test imports a generated tagged WAV, verifies -6 dB processing for its decoded stream, then switches to an untagged song and verifies the original-level fallback. Twelve storage/security tests cover recreation/privacy/Keystore plus linked metadata/gain round-trip, contact exclusion, repeated Passport import, long/custom tags, ambiguous/duplicate IDs, 2,000-record indexed matching and independent song edits.
- Android lint: **0 errors, 24 warnings**. Remaining warnings include newer dependency/tool versions, KTX/style suggestions, synchronous preference commits, the intentionally exported media service (controller trust is checked in code), and resource suggestions. Full report is included in `validation/lint.txt`; it has not been suppressed with a baseline.
- Optimized release APK: `assembleRelease` succeeded, including R8 and release vital lint. The APK was signed separately with a dedicated Songlane RSA-3072 key, verified with Android apksigner (v2/v3), and installed for a release smoke check. The key remains outside the repository. The public APK includes ARM64, ARMv7, x86 and x86_64 support and is not debuggable. A separate debug build remains available locally.
- Dependency inventory: 93 resolved runtime components with SHA-256 artifact hashes; direct or verified inherited Maven POM license evidence was resolved for all 93. This is a component inventory, not a vulnerability scan or legal certification.
- New cloud coverage: four unit tests verify integer money/rate/date/input policy. Twenty-one instrumented tests cover provider keys/migration/AAD, consent/payloads, strict outputs/receipts, transactional monetary limits/restart/concurrency, UTC rollover, cancellation/timeouts, transport headers/response limits, corrupt accounting and the Compose key/ceiling/deletion workflow. Total: **82 passing tests**.
- Local source secret-pattern scan found no matches for representative API-key/private-key patterns. This is not proof against every secret format.
- Kotlin sources formatted with ktfmt 0.64, whose downloaded artifact SHA-256 was checked against Maven Central before execution. No external CodeRabbit review was run because its CLI was not installed; the agent performed the local implementation/privacy review.

The final combined command was `gradlew.bat --max-workers=4 :app:testDebugUnitTest :app:connectedDebugAndroidTest :app:lintDebug :app:assembleRelease` and returned **BUILD SUCCESSFUL** for v0.3.0. Raw build and XML reports are in `validation/`. The debug workflow was exercised in the instrumented suite; the optimized signed APK received a separate installation and runtime smoke check.

## Fixes verified during the run

Rediscover had a mixed Integer/Long comparator default and was corrected to a Long default. Lint found Android 8 incompatibilities in retriever closure and a navigation-bar style attribute; both were fixed without raising minimum SDK. Private mode now clears the saved queue in the same database transaction and prevents stale snapshots from restoring it. Sleep timer requests are confined to in-process state instead of a mutable command on the exported media-service intent. Arbitrary controller-supplied audio URIs are resolved back to known local track IDs.

The new audio processor initially mishandled the shared empty pipeline buffer; real playback tests caught it, and a dedicated regression now passes. Gain is resolved from Media3 stream metadata at flush boundaries rather than the early UI track transition. Passport imports previously omitted user labels and duplicated playlists; they now preserve bounded labels and merge stable playlist IDs. Independent field edits update the latest stored track instead of overwriting a newly attached recording link or lyric.

## Limits and remaining release validation

The suite was run on one emulator. Bluetooth, calls/audio focus on real hardware, headphone unplug, Android Auto vehicle/DHU operation, widget/quick-settings host interaction, multiple OEM battery policies, large-library performance, auditory quality, TalkBack/manual accessibility and broader Android-version behavior have not been certified. Static minimum-API lint passed; this does not substitute for running Android 8.

Both provider paths were implemented from official Messages/Responses documentation. No paid request was made because no user API key was supplied. New tests verify local monetary admission and settlement under reviewed rates, concurrency, expiry, cancellation and malformed receipts; they do not prove account entitlement, language-model quality or provider invoices. CLOUD_AGENT.md documents the spending assumptions and limits. Local mode remains usable.

MusicBrainz client parsing, consent, endpoint, identification and rate policy were exercised with injected transport fixtures. A public search endpoint was inspected during development, but no end-to-end live Android lookup with a user-supplied monitored contact has been claimed. Normalization tests cover PCM math and stream integration, not measured acoustic loudness or subjective audio quality.

No Play Store listing, Play signing enrollment, naming clearance, external listener interviews, formal legal review or public backend has been completed. A public GitHub beta release was authorized; this does not establish those release gates. The source is a working local-player beta, not evidence that every future P2/P3 ambition in the supplied blueprint is shipped.
