# Security and data boundaries

Local audio access is granted through Android documents APIs or READ_MEDIA_AUDIO. Songlane asks for no microphone, contacts, location or broad filesystem management permission. Imported passports cannot introduce playable URIs. Exports exclude API keys and original file paths; they include sensitive listening history after an explicit warning.

Cloud parsing is disabled by default and uses fixed HTTPS Anthropic/OpenAI endpoints with redirects disabled. Only the selected provider key enters its authentication header. The chosen prompt and fixed parsing instructions leave after consent; library/history/audio never enter the payload. Limits: 2,000 prompt characters, 64 KiB response, 256 output tokens, 10 requests per UTC day and transactional daily/monthly local USD ceilings. Each dispatch first reserves the reviewed model's whole input-window cost plus output; validated usage settles once, unknown billing retains it. No automatic retries/failover. Date rollback, expired rates, unknown models and anomalous receipts block dispatch. Timeout/cancel disconnects transport; key changes/deletion cancel and join active parsing. Raw errors/provider bodies cannot expose prompts or credentials in UI messages. The ledger is conditional on reviewed prices and is not an account invoice control. Set provider billing controls too. Output can only fill a strictly typed bounded intent; users review settings and explicitly start playback. It cannot access arbitrary media/URLs/files/tools or override deterministic validation. See CLOUD_AGENT.md.

Keys use Android Keystore AES-GCM with fresh IVs and provider-bound authenticated data; no plaintext backup/export. Legacy Anthropic ciphertext migrates on use. Password fields are masked and excluded from activity state. The isolated ledger stores no prompts/responses/keys and is excluded from backups/Passport. Corruption disables cloud access without resetting spending; explicit full data deletion can clear a damaged ledger. Android backup is disabled. A rooted/compromised device can compromise a running app; client storage cannot guarantee protection there. Local deletion does not revoke a key; settings link to provider key management.

The media service only accepts this application, trusted platform/media controllers and its own notification controller. It supports local URI playback and cannot be used as a general network music proxy through the UI. Metadata and playlist text are displayed as text; no HTML/scripts or model instructions are executed. Folder recursion and passport imports have size/count bounds.

No telemetry, advertising SDK, backend account system or cloud synchronization is present. Playback/history remain local. Report security issues privately to the repository owner; establish a maintained public disclosure contact before a public release.

Optional MusicBrainz lookup is a separate consented metadata path. The client fixes the HTTPS host, disables redirects, bounds responses, identifies requests with a user-configured contact and serializes/rate-limits requests. Only selected title/artist or recording IDs leave the device; the contact is excluded from passports. Source-provided raw URLs, supplementary tags/ratings and scores are not retained. Imported recording-identity assertions cannot create trusted graph edges. ReplayGain reads bounded local metadata, validates numeric ranges and guards PCM saturation; it never uploads audio or rewrites source files.
